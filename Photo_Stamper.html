What is EXIF Stamper?
EXIF Stamper burns metadata — GPS coordinates, address, date, and time — directly onto your photos as visible text. Everything runs locally in your browser. No photos are ever uploaded to any server.
Layout
Left panelLoaded images list — click to select, hover for drag/move/remove controls CenterLive canvas preview — click or drag to reposition the stamp Bottom barStamp settings — fields, font, color, alignment, position presets Right panelEXIF data, address display, and Manual Override fields

Loading Photos
Drag & Drop
Drag photos or a .zip file anywhere onto the app window. Multiple files can be dropped at once.
Click to Browse
Click the drop zone (bottom-left) to open a file picker. Accepts JPG, PNG, WEBP, HEIC, TIFF, BMP, GIF and .zip archives.
ZIP Files
Photos inside a ZIP are automatically grouped by subfolder. Photos at the ZIP root go into a group named after the ZIP file.
File List Controls
  • Click — select and preview a photo
  • Checkbox — uncheck to download without stamp
  • ⠿ handle (hover) — drag to reorder within a group, move to another group, or drop onto + Drop to create new group
  • ⇄ button (hover) — open move-to-group menu
  • ✕ button (hover) — remove photo
✓ Tip

All new photos are placed in the "Ungroup" default group. Drag them to a named group or create a new one.

Stamp Positioning
Click or Drag on Canvas
Click anywhere on the preview to jump the stamp to that point. Drag the dashed ghost outline to fine-tune its position.
Preset Grid
The 3×3 grid (bottom-right of stamp settings) snaps the stamp to 9 positions: corners, edge centers, and middle.
Per-Photo Independence
Each photo stores its own stamp position as a ratio of image dimensions — so it stays proportional regardless of image size or orientation.
Apply Position to Group
The ↓ pos to group button copies the current photo's position to every other photo in the same group. This is a one-time copy — photos remain independent afterwards.
Groups
Default Group
All photos without an explicit group are placed in Ungroup. This group cannot be deleted, but photos can be moved out of it.
Creating Groups
  • From ZIP — subfolders automatically become named groups
  • Drag to zone — drag any photo to + Drop to create new group at the bottom of the list
  • ⇄ menu — hover a photo, click ⇄, choose "New group…"
Group Controls

Apply Overrides to Group
In Manual Override, switch scope to Entire group and click ↓ Apply to all in group to copy the current photo's date, time, GPS, and address to every photo in the group.
Manual Override
The right panel lets you manually set any metadata field per-photo — even for photos with no EXIF data. A Missing badge shows which fields are absent from EXIF.
Fields
DateMM/DD/YYYY — overrides EXIF date on stamp and in saved file TimeHH:MM:SS — overrides EXIF time GPSlat,lon (e.g. 26.184133,-80.263028) — triggers address auto-fill AddressFree text — does not change GPS coordinates
Nearest Address Suggestion
When GPS is present, a Nearest address box appears below the GPS field showing the closest mapped address found via Nominatim. Click ↑ Use this address to apply it.
🔍 Scan Photo for Metadata
Uses Tesseract OCR (free, runs in-browser) to read any text visible in the photo — GPS coordinates, date/time stamps, or addresses overlaid by another app. Found values are auto-filled into the override fields.

Excel Address Lookup
Load an ABF Fiber Distribution Record or Coordinates Excel file to instantly match every photo to the nearest address in the file — no geocoding needed.
How to Use
  • Click 📋 Load Excel for address lookup in the Manual Override panel
  • Select your ABF or Coordinates .xlsx file
  • All loaded photos are instantly matched — no clicking required
  • The nearest address within 500m is auto-applied to each photo's Address field
ABF File (Fiber Distribution Record)

Coordinates File
LatitudeColumn G LongitudeColumn H AddressColumn I — if two addresses are listed, the first is used
Geocoding Toggle
Loading an Excel file automatically turns ⚡ Geocoding: OFF to avoid unnecessary Nominatim requests. Toggle it back ON anytime — only photos without an address will be geocoded. Photos matched by Excel are never overwritten by geocoding.
✓ Tip

The ↺ Geocode button (next to the address box) lets you reverse-geocode a single photo on demand even when geocoding is OFF.

Stamp Checkbox
Each photo has a checkbox in the file list. Uncheck to download without any stamp — the original file bytes are used exactly as-is.

Geocoding
Geocoding converts GPS coordinates into street addresses. The ⚡ Geocoding button in the topbar controls whether this runs automatically.
⚡ Geocoding: ON (default)
When enabled, every photo with GPS coordinates is automatically reverse-geocoded as it loads. The address appears in the right panel and on the stamp.
⚡ Geocoding: OFF
No automatic geocoding. Addresses come from the Excel lookup or Manual Override. Toggle ON at any time — only photos without a manual address and without a geocoded address will be queued.
↺ Geocode Button
Appears next to the address box when geocoding is OFF and the photo has GPS. Click to reverse-geocode just that one photo on demand.
How It Works
Uses a two-step Nominatim strategy: first a reverse geocode to get the road name, then a structured proximity search within 120m to find the nearest mapped address node — ranked by Haversine distance. Falls back to standard reverse geocoding if no address nodes are found nearby.
Optional Paid Providers
LocationIQ5,000/day free — set GEOCODER='locationiq' and LOCATIONIQ_KEY at the top of the file OpenCage2,500/day free — set GEOCODER='opencage' and OPENCAGE_KEY at the top of the file
⚠ Note

Geocoding requires an internet connection. Photos without GPS coordinates are skipped. Nominatim is rate-limited to ~1 request per second — large batches take time.
