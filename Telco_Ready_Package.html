TMO FL TRP Automation — Telco Ready Package Generator

How it works
  1. Fill in site information (Site Number, AAV Provider, Address, Date).
  2. Upload ROOM_READY_TEMPLATE.pptx.
  3. Choose your upload mode:
    • Auto (Excel + Photos) — Upload the Excel mapping (Swift or Talonview) and all site photos. Photos are matched to categories automatically by filename.
    • Manual (Per Category) — Drop photos directly into each category (Front Page, Telco Box, Cienna, Fiber Box, AAV Power). No Excel or specific filenames needed.
  4. Review the Validation Report — matched photos appear in each section. Use the ➕ drop zone inside any section to manually add photos that weren't recognized, and the ✕ button to remove any photo.
  5. Click Generate TRP PowerPoint and download the file from the bar that appears.
